# nsw-maths-moderation
NSW K-6 Mathematics Moderation Portfolios (2022 Syllabus)

## What's here

- `index.html` — the Moderation Exemplar Finder (search and filter all portfolios).
- `nsw_*.html` — one moderation portfolio per rich task, Early Stage 1 to Stage 3.
- `moderation-tools.js` — shared tools used by every portfolio: professional judgement mode (hide decisions, judge, then reveal) and *Print this sample*.
- `MODERATION-REVIEW.md` — the October 2026 consistency and Common Grade Scale review, and how to add a new portfolio.

All portfolios use Common Grade Scale language (Extensive, Thorough, Sound, Basic, Elementary) rather than letter grades. Early Stage 1 portfolios use Thorough, Sound and Basic only, because the Common Grade Scale is not required for Kindergarten reporting.
