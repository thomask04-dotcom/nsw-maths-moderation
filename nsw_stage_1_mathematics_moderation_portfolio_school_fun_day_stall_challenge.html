Trade Combination: Option A ($12) + Option D ($15) + Option E ($8) = $35!

"First I checked if $25 could trade, but $35 - $25 = $10 and there is no $10 item. So I combined my other items: (12 + 8) + 15 = 20 + 15 = 35."

Missing Number Proof: 35 = 12 + 15 + [ 8 ]

Assessment Task Brief (Sequence 6)

Context: School Fun Day Activity Stall

Design an activity stall with a $50 budget. Choose at least 3 items from the Price Menu:

  • Option A: Small activity pack ($12)
  • Option B: Medium activity pack ($18)
  • Option C: Large game/art set ($25)
  • Option D: Bonus reward station ($15)
  • Option E: Mini decoration pack ($8)
  1. Total Cost: Add item prices using building to 10 or an empty number line.
  2. Calculate Change: Show change from $50 using the inverse shopkeeper method.
  3. Balanced Swap (Equality): Write an equivalent number sentence showing two combinations equaling the same total.
  4. Challenge: Trade for a friend's $35 Mega Pack using exact items.

NESA Common Grade Scale & Stage 1 Rubric

Key NESA Rubric Principle: Depth, Not Acceleration

Grade A reflects applying Stage 1 content readily to new situations. It does not require content from Stage 2.

Grade C (Sound): Demonstrates knowledge and understanding of the main areas of content; adequate level of competence in familiar situations using taught routines.
